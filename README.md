# 🐮 Коровосчёт

Совместный мобильный счётчик для **«Коровы 006» / 6 nimmt!**. Игроки открывают одну ссылку, вносят штрафные очки по раундам и видят общий счёт. Завершённые партии сохраняются в архиве.

## Что уже есть

- 2–10 игроков: имя и персонаж из каталога эмодзи;
- ввод штрафных очков каждого раунда;
- автоматический общий счёт и лидер (меньшее число лучше);
- напоминание при достижении 66 очков;
- отмена последнего раунда;
- новая игра с тем же составом или с пустым столом;
- архив партий: дата, участники, число раундов, финальный счёт и победитель;
- общая комната по ссылке вида `?room=ABC123`;
- обновление данных у всех открывших ссылку примерно раз в 2 секунды;
- адаптивный интерфейс для телефона и компьютера;
- локальный деморежим без базы данных.

## Быстрый запуск на компьютере

Это статический сайт — сборка и `npm install` не нужны.

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Пока Supabase не подключён, данные хранятся в `localStorage` только на текущем устройстве.

## 1. Создать базу Supabase для мультидоступа

1. Откройте [supabase.com](https://supabase.com), войдите и нажмите **New project**.
2. Выберите организацию, задайте имя проекта и пароль базы, затем дождитесь создания проекта.
3. В левом меню откройте **SQL Editor** → **New query**.
4. Скопируйте весь файл `supabase/schema.sql`, вставьте в редактор и нажмите **Run**.
5. Откройте **Project Settings** → **API** (в новом интерфейсе это может называться **Data API**):
   - скопируйте **Project URL**;
   - скопируйте публичный ключ **anon / publishable key**.
6. Откройте `config.js` и заполните значения:

```js
window.KOROVA_CONFIG = {
  SUPABASE_URL: "https://ВАШ_ПРОЕКТ.supabase.co",
  SUPABASE_ANON_KEY: "ВАШ_PUBLIC_ANON_KEY"
};
```

> `anon / publishable key` предназначен для фронтенда и может быть виден в браузере. **Никогда не вставляйте `service_role` или secret key.** Прямой доступ к таблицам закрыт; сайт вызывает только ограниченные SQL-функции.

Откройте сайт снова. Жёлтая плашка «Локальный режим» должна исчезнуть. Для проверки откройте одну и ту же ссылку в двух браузерах и добавьте раунд в одном из них.

## 2. Загрузить проект на GitHub

### Вариант через сайт GitHub

1. Распакуйте архив.
2. На GitHub нажмите **New repository**.
3. Задайте название, например `korova-score`, и создайте репозиторий **без** README/шаблонов.
4. Нажмите **uploading an existing file**.
5. Перетащите **содержимое папки** `korova-score` (файлы `index.html`, `app.js`, `config.js` и остальные), а не саму внешнюю папку.
6. Нажмите **Commit changes**.

### Вариант через Git

```bash
git init
git add .
git commit -m "Initial Korova score app"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/korova-score.git
git push -u origin main
```

## 3. Подключить к Vercel

1. Войдите на [vercel.com](https://vercel.com) через GitHub.
2. Нажмите **Add New…** → **Project**.
3. Выберите репозиторий `korova-score` и нажмите **Import**.
4. Framework Preset оставьте **Other**.
5. Build Command и Output Directory оставьте пустыми.
6. Нажмите **Deploy**.
7. После публикации откройте выданный Vercel-адрес. Сайт сам создаст код комнаты в URL.
8. Нажмите кнопку со стрелкой рядом с кодом комнаты и отправьте скопированную ссылку остальным игрокам.

Каждый код в параметре `room` — отдельный стол. Например, `?room=FRIDAY` и `?room=FAMILY` хранят разные игры и архивы.

## Обновление сайта

Измените файлы и отправьте новый коммит в ветку `main`. Vercel автоматически запустит повторный деплой.

## Важные ограничения текущей версии

- Авторизации нет: любой человек со ссылкой на комнату может менять её счёт. Используйте непредсказуемый код и не публикуйте ссылку открыто.
- Синхронизация работает опросом базы примерно раз в 2 секунды — это проще и надёжнее для небольшой домашней игры.
- Игроков можно добавлять и удалять только до записи первого раунда, чтобы не нарушить историю счёта.
