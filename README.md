# 🐮 Коровосчёт

Совместный счётчик очков для настольной игры **«Корова 006» / 6 nimmt!**. Все за столом открывают одну ссылку: очки вводятся с телефона (с одного или с нескольких сразу), счёт виден на компьютере и на большом экране телевизора. Завершённые партии попадают в архив и статистику.

Рабочий сайт: <https://6-nimmt.vercel.app>

## Возможности

### Партия
- 2–10 игроков. Быстрое добавление: поиск, несколько игроков одной кнопкой, «Часто играют», сортировка по числу партий или Эло.
- Удаление игрока до первого раунда — с кнопкой «Вернуть» вместо системного окна.
- Ввод очков раунда:
  - на телефоне — своя цифровая клавиатура, «Далее» переходит к следующему игроку без очков, страница сама подкручивается к нужной строке;
  - на компьютере — обычные поля, Enter переходит к следующему игроку, порядок — сверху вниз по колонкам;
  - несколько человек могут вводить одновременно со своих телефонов, черновики синхронизируются;
  - рядом с игроком видно, каким станет счёт («35 → 49»);
  - если сумма раунда больше 100, приложение попросит проверить опечатку.
- Рубеж 66 — не конец игры: партия продолжается, пока её не завершат вручную, побеждает меньший счёт.
- Пьедестал тройки, таблица остальных мест, таблица «Ход партии» по раундам (номер раунда — исправить раунд).
- События раунда (смена лидера, рывок, рекорд) и реакции у аватаров после записи раунда: 👑 новый лидер, 🐮 переход за 66, 😎 ноль очков, 😭 больше всех, 🍀 попадание в карту удачи.
- Экран «Партия завершена»: победитель, победный клич, карта удачи, «Судьба», места, сюжет партии и шуточные номинации.

### Табло на телевизоре
Кнопка «Табло» или адрес `?display=tv`. Крупный пьедестал с живыми аватарами, места 4–10, кружки «кто уже ввёл очки», бегущая строка с событием раунда, финальная заставка с победителем и его кличем.

### Профиль игрока
- Персонаж-эмодзи из 6 групп, в том числе «Герои и мемы». На пьедестале, табло и экране победителя эмодзи «живые» (анимация Google Noto).
- Цвет и узор карточки. Часть вариантов открывается достижениями (победы, сыгранные партии).
- Рамка аватара за победы: Бронза — 3, Серебро — 8, Золото — 15, Легенда — 25. По умолчанию показывается лучшая открытая.
- Корона — у лидера рейтинга Эло. Её нельзя выбрать, только отобрать.
- Титул, победный клич и **карта удачи** (1–104): 🍀 очки раунда оканчиваются на ту же цифру, что и карта; 🎯 «Судьба» — итог партии равен номеру карты.

### Архив и статистика
- Архив с фильтрами (игрок, победитель, даты, число игроков, тип партии) и карточкой партии: счёт, ход игры, номинации, копирование в мессенджер.
- Статистика: рейтинг Эло и форма, обзор и книга рекордов, зал наград, сравнение двух игроков, личная карточка игрока с прогрессом рамок.

### Режим организатора
Вход по PIN (кнопка с замком). Нужен для исправления и удаления архивных партий, объединения профилей, журнала изменений и страховочных копий. Для обычной игры не требуется.

## Как устроен проект

Статический сайт без сборки: HTML + CSS + JavaScript. Данные — в Supabase, доступ только через SQL-функции.

```text
index.html                 — страница приложения
app.js                     — интерфейс и вся логика
styles.css                 — базовые стили (исторические)
redesign.css               — стили нового дизайна v8+, подключается после styles.css
config.js                  — адрес и публичный ключ Supabase
service-worker.js          — офлайн-кэш и обновления (имя кэша = версия)
version.json               — текущая версия для проверки обновлений
manifest.webmanifest, icons/, favicon.svg — установка как приложение
supabase/schema.sql        — исходная схема
supabase/migrations/*.sql  — миграции по версиям (v1.2 … v8.1)
vercel.json                — настройки публикации
```

Комната: на рабочем адресе всегда открывается комната `EXBVHN`. На копиях сайта (preview) можно открыть любую тестовую комнату, например `?room=TEST01`; сверху тогда видна жёлтая плашка «Тестовая версия».

## Разработка и публикация

1. Работайте в ветке `redesign`: загрузите изменённые файлы в неё (GitHub → выбрать ветку → Add file → Upload files).
2. Vercel сам соберёт копию сайта. Постоянная ссылка на ветку: `https://6-nimmt-git-redesign-<аккаунт>.vercel.app/?room=TEST01`.
3. Когда всё проверено — Pull request `redesign` → `main` → Merge. Рабочий сайт обновится за 1–2 минуты.
4. При каждом выпуске меняйте версию в трёх местах: `APP_VERSION` в `app.js`, `CACHE` в `service-worker.js` и `version.json`. Тогда у игроков появится плашка «Доступно обновление».

Откат: Vercel → Deployments → прошлая Production-сборка → Instant Rollback.

Локальный запуск без базы: `python3 -m http.server 8080` и открыть `http://localhost:8080`. Без настроек Supabase данные хранятся в `localStorage` этого устройства.

## База данных (Supabase)

База одна на рабочий сайт и на копии — тестируйте в отдельной комнате.

Новая установка: Supabase → SQL Editor → выполнить `supabase/schema.sql`, затем по порядку все файлы из `supabase/migrations/`. Существующей базе нужны только новые миграции. Все миграции можно безопасно запускать повторно.

Последние миграции:
- `v8.0.sql` — рамка и победный клич профиля;
- `v8.1.sql` — карта удачи, новые цвета и узоры профиля.

В `config.js` указывается только публичный **anon / publishable key**. Никогда не вставляйте `service_role` / secret key.

## Ограничения

- Авторизации игроков нет: любой со ссылкой может вводить очки. Не публикуйте ссылку открыто.
- Синхронизация — опросом сервера раз в несколько секунд.
- Состав игроков меняется только до первого раунда.
